# Personal Portfolio Website

## Project Overview

This is a responsive Personal Portfolio Website developed using **HTML, CSS, and JavaScript**. The website showcases my profile, technical skills, projects, achievements, and contact information in a clean and professional manner.

The portfolio is designed to be fully responsive and provides a smooth user experience across desktop, tablet, and mobile devices.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Flexbox
- CSS Grid
- Git & GitHub

---

## Features

- Responsive Navigation Bar
- Hero Section with Introduction
- About Me Section
- Skills Section
- Projects Showcase
- Achievements Section
- Contact Section
- Download CV Button
- Smooth Scrolling
- Typing Animation
- Interactive UI
- Responsive Design
