# Employee Management System

## Project Overview

The Employee Management System is a simple web application built with HTML, CSS, and JavaScript. It helps users manage employee records by adding, viewing, searching, filtering, and deleting employees.

## Features

* Add new employees
* View all employees
* Search employees by name
* Filter employees by department
* Delete employee records
* Responsive design for desktop, tablet, and mobile

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Start managing employee records.

## Future Improvements

* Edit employee details
* Save data with Local Storage
* Sort employees
* Export data
* Dark/Light mode

This project is a beginner-friendly example of web development using HTML, CSS, and JavaScript.
